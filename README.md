# UPFOREX / Visual Sections Fix

Open `index.html` directly in Chrome, Edge or Firefox. No npm or Angular required.

## What changed

- **The World Is Bigger Than One Market**: Added full photo panel, market photo inset, two small facts and animated chart lines.
- **Meet Your Platform**: Added trading workstation image in the bright green intro. Existing MT5 device image below remains.
- **Better Together**: Replaced abstract empty rings with a photographic partnership collage and animated overlays.
- Typography remains the original UPFOREX scale (48px desktop hero, 36px desktop section headings, 36px mobile hero, 24px mobile section headings).
- Brand black `#0D0D0D` and neon green `#3CFF19` preserved. All other site sections and existing links unchanged.
- Existing animations retained. New panels add image zoom, ambient movement, scanning light and pointer-based depth.
- All images are local assets from the UPFOREX project. No external image requests.

## Structure

- `index.html` - homepage
- `css/style.css` - original CSS plus scoped section fixes at the end
- `js/main.js` - original JS plus optional visual depth interaction
- `assets/` - original images and video

Images used in the new sections are **illustrative visuals**, not evidence of actual broker staff or partnerships.

Before publishing, review financial risk statements, legal terms and destination links.
